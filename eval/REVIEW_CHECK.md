# Проверка правок «независимая сверка и соединительная ткань»

2026-09-17. Продолжение [MERGED_EDIT_CHECK.md](MERGED_EDIT_CHECK.md), та же методика.
Проверяются четыре правки SKILL.md из ветки `skill/independent-review` (f33d057):
сверка чистовика свежим агентом по `references/review.md`, соединительная ткань в
факт-замке (длительность, причина, реакция), рамка в сверке, проверка на
переносимость. Вопрос один: не стало ли хуже по смыслу, голосу и ясности.

## Прогон

```
.venv/bin/python eval/probe_installed_skill.py \
  --skill skills/humanizer-ru \
  --control-skill <skills/humanizer-ru из main, v3.26.2> \
  --extra-cases eval/local_edit_cases.json \
  --output eval/out/review-two-arm-20260917 --repeats 3 --workers 3 --seed 9172026
```

13 исходников × 2 условия × 3 повтора = 78 вызовов через Claude CLI 2.1.272,
78/78 успешных. Пробник вставляет SKILL.md, edit-log.md и catalog.md в один запрос
и субагентов не поднимает, поэтому сам бриф проверяющего здесь не измеряется:
измеряется, не портят ли новые правила самого SKILL.md редактуру. Слепая оценка
по [PROBE_RUBRIC.md](PROBE_RUBRIC.md) двумя агентами по 39 пакетов
(`review_a.json`, `review_b.json`); оценщики не видели меток и не запускали сканер.

## Вывод

Правки не ухудшают редактуру: ноль смысловых и голосовых замечаний в обоих
условиях, ясность на уровне, балл сканера в пределах шума трёх повторов. Эффект
самого брифа проверяющего (`references/review.md`) этим прогоном не измерен: он
