# ru-humanizer

Сканер следов нейросети в русском тексте из проекта
[humanizer-ru](https://github.com/ilyautov/humanizer-ru). Считает балл чистоты от 0 до 100,
находит 21 жёсткий запрет и 67 признаков машинной манеры, проверяет факт-замок между
исходником и правкой. Правила откалиброваны на 55 тысячах размеченных русских текстов.
Работает офлайн, текст никуда не отправляется.

mcp-name: io.github.ilyautov/humanizer-ru

## Командная строка

```bash
pip install ru-humanizer
ru-humanizer статья.md
ru-humanizer статья.md --genre academic
echo "текст" | ru-humanizer -
ru-humanizer чистовик.md --before исходник.md
```

Код выхода: 0 чисто, 1 есть жёсткие запреты, 2 в чистовике появился факт, которого
не было в исходнике. Флаг `--json` отдаёт машинный отчёт.

## MCP-сервер

Тот же пакет поднимает MCP-сервер по stdio с двумя инструментами:

- `scan_text`: балл, штрафы, запреты и маркеры с позициями, ритм, морфология, структура.
- `compare_texts`: балл «было и стало» и факт-замок: что пропало, что появилось, какие
  кванторы вроде «впервые» или «единственный» возникли без источника.

Конфигурация для Claude Desktop, Cursor и других клиентов:

```json
{
  "mcpServers": {
    "humanizer-ru": {
      "command": "uvx",
      "args": ["ru-humanizer", "mcp"]
    }
  }
}
```

## Что это не делает

Балл считает плотность оборотов, по которым читатель узнаёт машинную манеру. Это не
вероятность авторства и не детектор: инструмент не обходит проверки и не выносит
вердиктов, он показывает, что править. Полный каталог признаков, скилл для агентов и
расширение Chrome лежат в репозитории.
