# Changelog

История версий humanizer-ru. Вынесена из `SKILL.md`, чтобы рабочий промпт не тащил
историю изменений в контекст модели на каждый запуск (лишние токены + когнитивная
нагрузка). Сам скилл должен содержать только операционные правила.

## v3.8 — Упаковка для дистрибуции: slash-команды и витрина

Релиз про распространение, сам скилл не менялся.

- **Slash-команды плагина** (`commands/`): `/humanize` — полный рерайт по
  скиллу, `/audit` — аудит без правки с проводом в детерминированный сканер.
- **PRIVACY_POLICY.md** — у проекта нет серверной части, текст никуда не
  уходит; зафиксировано явно (требование каталогов плагинов).
- **CONTRIBUTING.md** — окружение, проверки, правило «маркер живёт в двух
  местах» (SKILL.md + markers.py + тест).
- **Шаблоны issues**: ложное срабатывание, новый маркер, баг + контакты.
- **assets/**: иконка 512/256/128 и social preview 1280×640 в стиле сайта.

## v3.7 — Факт-замок: запрет выдуманной конкретики + числовой якорь ритма

Находка строгого 27b-судьи: очеловеченная версия `marketing_gpt_01` выдумала факты
(«сорок брендов», «1200 заявок»), которых нет в исходнике, и meaning упал до 30.
Корень — сам скилл: примеры паттернов 1-2 и пункт «Конкретен» поощряли вписывать
конкретику, не оговаривая, откуда её брать.

- **«Факт-замок»** (Шаг 3, приоритет над любым паттерном): факты исходника
  неприкосновенны, ДОБАВЛЯТЬ факты, которых нет в исходнике, запрещено; нет
  конкретики — оживляй голосом/ритмом или спроси пользователя. + пункт чеклиста.
- Примеры паттернов 1-2 аннотированы («числа из исходника, не выдумывай»),
  пункт «Конкретен» получил ту же оговорку.
- **Числовой якорь ритма** в чеклисте: на каждые 5-7 предложений хотя бы одно
  ≤4 слов и одно ≥20 (два текста корпуса проваливали CV<0.45 при чистой лексике).
- Эталонные humanized-версии (`marketing_gpt_01`, `business_gemini_06`,
  `docs_gpt_07`) перегенерированы по v3.7: CV 0.71-0.80, баны 0, маркеры ≤1.
- **20-я категория сканера «Артефакты копипасты»** (однозначные улики вставки из
  чат-бота): `:contentReference[oaicite:N]`, `oai_citation`, `utm_source=chatgpt.com/openai`,
  `grok_card://`, `attached_file://`, `vertexaisearch`-redirect, `turnN(search|fetch|file)N`,
  `citeturn...`, `【N†source】`, `[citation:N]`, `](sandbox:/mnt/data/`, невидимые U+E200-E204,
  `</think>`. Сканер научился regex-маркерам (префикс `re:`). Копайлот-сноски `[^N^]`
  НЕ включены: высокий риск ложных срабатываний на Markdown-сноски. Один артефакт =
  однозначный вердикт сканера, минуя шкалу. + тесты, секция в SKILL.md.

## v3.6 — Сканер едет со скиллом, машинная половина «Аудита» подключена

`scan.py` + пакет `humanizer_metrics` переехали из корневого `scripts/` внутрь скилла
(`skills/humanizer-ru/scripts/`) и теперь устанавливаются вместе с ним (формат Agent
Skills поддерживает `scripts/` одинаково в Claude Code и Codex). Режим «Аудит» в
SKILL.md получил провод: при доступном python3 c `razdel`+`pymorphy3` скилл сначала
запускает сканер (детерминированные HARD BANS/маркеры/ритм/морфология), поверх
добавляет суждение (ложные срабатывания, приоритеты). Фоллбэк мягкий: нет
зависимостей — предложить pip-однострочник и работать по каталогу, как раньше.
Линт пополнился гардом «сканер внутри скилла и подключён». Попутно починен CI-смоук
(ссылался на несуществующий файл корпуса).

## v3.5 — Верификация источников, тулинг, eval-харнес

Релиз про достоверность и измеримость, не про новые паттерны.

**Верификация цитат.** Все 35 академических утверждений (27 arxiv-ID + 8 именованных
исследований) проверены по первоисточникам. Из рабочего промпта (`SKILL.md`) удалены
все inline arxiv-ID и неподтверждённые точные числа: они не меняли поведение модели,
но били по кредибилити. Что именно подтвердилось, исправлено и удалено — в новом
[SOURCES.md](SOURCES.md). Конкретно убраны/исправлены:
- Biber framework / noun/verb 3:1 (неверная атрибуция, статья про перевод) — тезис
  оставлен качественно, ложная ссылка убрана
- CoPA «+57.7% улучшения детекции» — CoPA это атака на детекторы, не метод; цифра убрана
- PNAS 2025 «мат в 100 раз реже» — публикация не найдена, число убрано
- метафоры «F1=30.4» — цифры не совпадают с источником, убраны
- DivEye — исправлен ID; AINL-Eval — снята неверная атрибуция к RuRoBERTa
- «AI больше радости» — исправлено на «эмоционально ровный» (источник говорит обратное)

**Две новые секции в скилле (заимствованы у blader/humanizer):**
- «Как звучит живой текст» — позитивный якорь: к чему править, а не только что убирать
- «Ложные срабатывания» — когда маркер НЕ приговор (осмысленная триада, авторское
  тире, намеренный повтор, формальный регистр по жанру); контроль переусердствования

**Before/after** добавлены к паттернам #2, #22, #24, #44, #46.

**Changelog вынесен** из `SKILL.md` в этот файл — рабочий промпт похудел с 532 строк.

**Детерминированный тулинг (`scripts/`):**
- `humanizer_metrics` — Python-пакет метрик (pymorphy3 + razdel): HARD BANS + сканер
  19 категорий, burstiness (дисперсия длины предложений, тире), морфология
  (сущ./глаг. ratio, номинализации)
- `scan.py` — CLI-сканер (машинная половина режима «Аудит»)
- `lint_skill.py` — self-test: тестирует SKILL.md против собственных правил (все 52
  паттерна, 20 банов, ноль тире в одобренных примерах, синхронизация копий)

**Eval-харнес (`eval/`):** стратифицированный корпус, метрики до/после, адаптеры
реальных детекторов (GPTZero/Originality/RuRoBERTa, graceful без ключей), LLM-судья,
regression-гейт, контроль переусердствования на человеческих текстах, авто-`RESULTS.md`.

**Длинное тире — исключение по запросу пользователя.** Бан длинного тире «—»
остаётся абсолютным по умолчанию (живой неформальный русский ставит дефис, не «—»).
Но если пользователь явно говорит, что он проф. редактор / нужна издательская
типографика, скилл оставляет грамотные длинные тире. Сам это исключение не включает.

**Фикс ложного срабатывания сканера.** HARD BAN «данный» больше не ловит
существительное «данные/данных» (data) — был ложный бан на ML/статистических
текстах. Regex сужен до единственного числа (как в самом HARD BAN). Закреплено
регресс-тестом.

**Тесты (`scripts/test_markers.py`):** 13 регресс-проверок (включая «данные» ≠ бан,
тире, разделение AI/человек по метрикам).

**CI:** `test_markers` + `lint_skill` + метрики-прогон на каждый PR (бесплатно, без ключей).
