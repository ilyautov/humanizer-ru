# Проверка локальной редакторской инструкции

2026-09-10. **Результат: существенное улучшение в этом сравнении; кандидат
сохранён для следующего этапа, не установлен.** 195/195 ответов завершены,
195 слепых оценок получены. Осталась одна смысловая ошибка на контроле.

## Гипотезы до запуска

1. Полная перепись абзаца по числу маркеров увеличивает риск смысловой достройки.
2. Требование добавлять голос провоцирует авторские реакции редактора.
3. При большом каталоге модель выполняет отдельные правила вместо задачи правки.

Это альтернативные объяснения; пакетный эксперимент ниже не изолирует вклад
каждого. Сравниваем полезность компактного режима, не доказываем одну причину.

## Дизайн

13 исходников × 3 условия × 5 повторов = 195 вызовов.

- control: обычное задание редактору, без скилла;
- skill: официальная 3.23.0 целиком — SKILL.md, edit-log.md, catalog.md;
- candidate: самостоятельная компактная инструкция локальной правки.

Система, пользовательское задание, исходники и запрошенная модель одинаковы.
Модель claude-opus-5; фактическое имя проверяется по метаданным ответа.
Семь прежних кейсов регрессионные; шесть новых синтетических кейсов проверяют
оффер, ограниченные измерения, содержательное противопоставление, полезную
навигацию, авторский фрагмент и структурную риторику без словарных клише.
Синтетические кейсы не выдаются за человеческий корпус.

Порядок перемешан (seed 9122026). Пакеты для оценки содержат только исходник,
результат и ID. Рубрика: PROBE_RUBRIC.md. Оценщики не получают имя варианта,
инструкцию кандидата или желаемый результат. Пять повторов — устойчивость,
не пять новых тем. Не судить по баллу сканера.

## Критерий до раскрытия

- Все 195 ответов завершены; ошибки запуска не скрыты.
- Смысловых замечаний у кандидата хотя бы вдвое меньше, чем у официальной
  версии, и не больше, чем у обычного редактора. При нуле у обоих контролей
  улучшение по этой оси не доказано.
- Нет новых смысловых/голосовых регрессий на сохранительных кейсах
  (энциклопедия, voice, study, story, contrast, navigation, author).
- На шести редактируемых кейсах (expert, business, docs, offer, report,
  scaffolding) риторических флагов меньше официального варианта и не больше
  обычного редактора. Число улучшений ясности не меньше обычного редактора,
  ухудшений не больше. Не принимать кандидат, который просто ничего не правит.
- Если спорная оценка меняет решение, провести отдельный слепой пересмотр.
- Результат позволяет продолжить проверку, но не доказывает универсальность.
  Установленную версию в рамках этого эксперимента не заменять.

## Как проверено

Три независимых контекста оценщиков: A — ID 001–065, B — 066–130,
C — 131–195. Все читали одну PROBE_RUBRIC.md и только слепые пакеты.
Файлы `review_a_part1..3.json`, `review_b_part1..4.json`,
`review_c_part1..3.json` записаны до раскрытия вариантов. Это оценка
ассистентами, не человеческая панель и не по три независимые оценки каждого ответа.

До раскрытия основной агент перечитал все отмеченные strict/voice/rhetoric
пары. По sample-019 попросил пересмотреть «свет наш»: естественное чтение
«свет предоставляет студия» не доказывает изменения владения. Оценщик снял
strict и оставил спорное замечание; модельный вариант при этом оставался скрыт.

Проверены: 195 валидных уникальных оценок, 39 ячеек по пять вызовов,
точное совпадение исходников и ответов между raw/blind, SHA-256 каждого промпта,
состав слепого пакета, неизменность пакетов инструкций. Все ответы имеют
`claude-opus-5` в modelUsage; часть метаданных также содержит вспомогательную
Haiku. Запускатель завершился кодом 0. Повторно прошли 9 unit-тестов,
quick_validate кандидата, git diff --check; repo SKILL.md не изменён и совпадает
с установленной копией.

## Решение

Сохранить кандидата `eval/candidates/local-edit/SKILL.md` как экспериментальный
режим. Не менять текущую установку, каталог, онлайн-сканер или релиз.
Следующий узкий тест — недопустимая достройка количества/исключительности на
новых материалах, затем проверка совместимости режима с основным скиллом.
Не дописывать правило под Байкал и не считать повтор этой одной темы проверкой
общей сохранности. Перед релизом нужна оценка реальных авторских текстов и
естественности читателями; нынешний результат этого не заменяет.
